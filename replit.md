# Project setup

This is a React, TypeScript, and Vite web app.

## Run

- Start the app with `npm run dev`.
- The development server listens on `0.0.0.0:3000` for Replit Preview.

## Build

- Create a production build with `npm run build`.

The `GEMINI_API_KEY` entry in `.env.example` is not currently referenced by the app, so it is not required to run the project.
